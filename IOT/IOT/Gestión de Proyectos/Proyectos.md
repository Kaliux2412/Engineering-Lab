Un proyecto requiere de gestión y tiempo limite, considera el tiempo y esfuerzo y costo para cumplirse.

Ciclo de vida de un proyecto: son las fases en las que se divide un proyecto y sus tareas que se necesitan para completarse.

Fases: Inicio
- Planificación: definición detallada del proyecto
- Ejecución : llevar acabo el plan de gestión 
- Control: Medir, supervisar regularmente
- Cierre: Formalizar la aceptación
